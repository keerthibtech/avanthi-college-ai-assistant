# 🤖 Avanthi College AI Assistant

An AI-inspired web-based college information assistant developed for a hackathon.

The **Avanthi College AI Assistant** helps students and visitors quickly access important college information through a simple and interactive chatbot interface.

---

## 🚀 Project Overview

Finding college information such as courses, admissions, fees, hostel facilities, transportation, placements and student activities can take time.

This project provides a centralized conversational interface where users can ask questions naturally and receive relevant information instantly.

The project is designed as a lightweight **frontend-based AI assistant** using HTML, CSS and JavaScript.

---

## 🎯 Problem Statement

Students and visitors often need to search through multiple sources to find basic college information.

The objective of this project is to create a simple digital assistant that provides quick access to commonly requested college information through a conversational interface.

---

## 💡 Solution

The Avanthi College AI Assistant provides:

- 🤖 Interactive chatbot interface
- 🎓 Course information
- 📝 Admission information
- 💰 Fee information
- 🏠 Hostel information
- 🚌 Transportation information
- 💼 Placement information
- 📍 Campus location
- 📞 Contact information
- 🎉 Events and student activities
- 📝 Examination information
- 🎯 Vision and Mission

Users can either type their questions or use quick-question buttons.

## ✨ Key Features

### 🤖 Interactive Chatbot

Users can type questions in natural language and receive relevant responses.

## 🧠 How It Works

The chatbot uses a JavaScript-based knowledge base.

1. User enters a question.
2. The question is normalized.
3. Relevant keywords are detected.
4. The system identifies the most suitable information category.
5. The corresponding answer is displayed in the chatbot.
